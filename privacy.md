# Privacy Policy: Hermes (personal)

Last updated: 24 October 2026

Hermes (personal) is a personal assistant used only by its developer, Ian Martens, on his own server. It is not offered to anyone else.

## Data accessed
With the owner's consent, the app accesses data from the owner's own Google account: Gmail messages and Google Calendar events and calendar lists.

## How data is used
Data is used only to provide the owner's assistant features: summarising mail, tracking follow-ups, reading calendars, finding free time slots, and creating events in the owner's own calendar. It is not used for advertising, profiling or any other purpose.

## Storage and sharing
Google data is processed on the owner's own home server. Only the OAuth access token is stored there. Mail and calendar content is not sold, shared with or disclosed to any third party, other than to the AI model provider as strictly needed to answer the owner's own requests. Data is not used to train generalised AI models.

## Limited Use
The app's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Retention and deletion
The owner can revoke access at any time at https://myaccount.google.com/permissions. Deleting the token from the server removes the app's access.
