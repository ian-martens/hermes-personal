# Hermes (personal)

Hermes (personal) is a private, single-user assistant that runs on its owner's own home server. It connects to the owner's own Google account, with the owner's consent, to:

- read Gmail messages, so the owner can get summaries and follow-up reminders
- read Google Calendar events and find free time slots
- add events to the owner's own calendar

The app is not a public service. It has one user: its developer. It does not send email on the owner's behalf and does not invite other people to events.
